# UTS REST Client Android

Aplikasi Android untuk mengakses REST API menggunakan Retrofit dan menampilkan data barang.

## Teknologi
- Java
- Android Studio
- Retrofit
- REST API
- Laravel Sanctum Authentication

## Fitur
- Login menggunakan API
- Menyimpan token autentikasi
- Menampilkan daftar barang
- Logout dan menghapus token autentikasi
